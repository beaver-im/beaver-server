# 11.3 跨仓检查

[返回本章](README.md) · [全书目录](../README.md)


1. 子仓同样遵守数据库独占与物理隔离（[第 6 章](../06-data/)）；先确认提供者真实 `.api` 路径、鉴权、字段/信封；调用者的 remote 名称不一定与仓名相同（doc/circle/moment/agent/ai 需逐个核对）。
2. 提供者先改契约生成，实现并验证；调用者更新本仓 types/remote 和 XxxApi 方法，不能引对端模型。
3. 列跨仓同步修改清单（提供方、消费方、机器票/权限与错误语义），各端同步更新；敏感值不入手册。
4. Python Agent 走下章；跨仓不要 etcd RPC/跨库。没读过的子仓细节标未核实，不套用主仓“已达标”。

本次手册集中在 beaver-server；没有给子仓加规则、改业务或执行生成。
