# 第 14 章　任务交接与归档

[返回目录](../README.md) · [模板](template.md)

稳定规范写 standards/modules，不写在任务流水账里。交接只存目标、当前差异、检查结果、未完与下一步。
用户没有要求持久交接的小任务可以直接聊天总结，避免每个 AI 自动制造 md。

需要落盘时：新建 `docs/tasks/active/<任务号或日期-主题>.md`，从模板复制；同一任务持续更新一份。
完成后经确认移入 `docs/tasks/archive/<年份>/`，标完成日期和可复查差异/提交（没有提交就写未提交，不编号）。
active/archive 目录按实际任务创建，本次不虚构业务任务或占位“已完成”。不定期确认后清理已无价值历史，不能自动删用户资料。
新交接文件加入 knowledge-checks.json 的 documents，归档移动也同步索引。
代码上下文不是永久记忆：下一位先读交接、看实际 git diff 和局部源码，再继续；并发修改优先保护。
