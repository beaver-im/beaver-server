# 8.3 评审清单

[返回本章](README.md) · [全书目录](../README.md)


规则正文只在对应主章节，本清单只列检查点；勾选前点进链接核对原文。

- [ ] 无双轨路由/废弃入口残留；受影响调用方已全量同步（[AGENTS.md](../../AGENTS.md)）。
- [ ] 本服务只连自有库；无他服务 DSN、跨库 SQL/JOIN、他域 models；跨服务走接口（[第 6 章](../06-data/)）。
- [ ] 业务归属明确；不跨域 models/DB、不跨仓 RPC；无转发壳与残留文件。
- [ ] 新接口先有 `.api/.proto`；生成命令/cwd/工具版本/模板可追溯；未手造生成物（[第 3 章](../03-contracts/)）。
- [ ] remote 业务方法 `Api` 后缀、每接口独立 Req/Res、URL/tag 对齐对端、失败不吞（[第 4 章](../04-boundaries/)）。
- [ ] `.api` 按业务类别分组、保护/公开面与中间件匹配、单入口生成（[第 3 章](../03-contracts/)）。
- [ ] API↔RPC 显式映射；字段与信封同步（[第 4 章](../04-boundaries/)）。
- [ ] 鉴权前缀、公开 group、机器票映射、oauth 单向兼容按[第 5 章](../05-runtime/)核对；缺票/伪造头/越权用例验过或注明未验。
- [ ] context/超时贯穿；错误无吞没、对外不泄露内部细节；日志无秘密；并发资源能停止。
- [ ] 事务与消息的失败窗口、幂等/重复、版本与删除同步被考虑；升级方案不依赖默认删库（[第 6 章](../06-data/)）。
- [ ] 实际测试命令与结果可复查，未做项写明；旧报告通过不当作本次通过。
- [ ] 知识更新集中到唯一主章；他人修改和暂存保留。
